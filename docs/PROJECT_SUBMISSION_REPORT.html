1. Executive Summary & Business Value

The Support Activity Tracker is a specialized operations management platform built for SRE and Support Engineering teams at Npontu Technologies. It addresses shift handover fragmentation by offering real-time checklist tracking, immutable compliance logging, SRE monitoring metrics, multi-format reporting (PDF print & CSV export), and user role management.

3. 4-Tier Architecture Breakdown

  • Tier 1 — Presentation Layer (UI): Blade Templates, Livewire 3 real-time polling, Tailwind CSS v4 design system, responsive mobile drawer navigation, and animated SRE splash screen loader.
  • Tier 2 — Application / HTTP Layer: Security middleware stack (Auth, Role Enforcement, Trusted Proxies, CSRF protection), Form Request validation, and Controllers.
  • Tier 3 — Business & Service Layer: Action classes (`CreateActivityAction`, `UpdateActivityStatusAction`), `AuditService`, `ReportingService`, and Notification mailables (`WelcomeNotification`, `AdminPasswordResetNotification`).
  • Tier 4 — Persistence & Data Layer: Eloquent ORM Models with soft-deletes, polymorphic audit morphs, and Render Free PostgreSQL database connection.
